Solmaris is an open-world crime game set in an original sun-soaked coastal city. Explore five districts on foot and by car, steal cars, dodge the police, and run six missions in "The Solmaris Job" story chain — with traffic, pedestrians, a 0–5 star wanted system, combat, shops, and a living HUD and minimap.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/solmaris-out node main.ts
```

Requires Node 22. The game renders in a 2.5D Canvas view; screenshots are generated deterministically with `?shot=title|driving|chase|mission`.
